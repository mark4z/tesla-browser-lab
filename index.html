如何理解测试结果
  • “声明支持”只是 API 的答复；“输出帧”才表示这个合成样本实际完成了解码。
  • WebCodecs 测试使用默认加速策略，统计 120 帧输出吞吐，不是屏幕帧率，也不能证明使用了硬件解码。
  • 播放器帧率来自视频帧回调的合成提交计数；丢帧来自浏览器播放质量计数。浏览器不提供时显示“不可测”，不会用页面刷新帧率替代。
  • 实际硬件型号、Ryzen 代际、车辆固件、手机投屏协议和端到端延迟均无法由此页确认。通过短样本不代表能稳定投屏或持续运行。
  • 只在当前浏览器测试，不读取车辆接口，不请求摄像头、麦克风或定位。应用不主动上传结果；托管服务仍会收到正常页面和样本请求。
